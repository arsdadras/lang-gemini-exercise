# Clean Committer Skill

Follow these guidelines for crafting commit messages and managing git state:

1. **Conventional Commits Specification:**
   - Format: `<type>(<scope>): <short description>`
   - Common types: `feat`, `fix`, `refactor`, `test`, `docs`, `chore`, `perf`.

2. **Imperative Mood:**
   - Use imperative present tense (e.g. "add feature", "fix bug", not "added" or "adds").

3. **Atomic Changes:**
   - Commit only logically related changes together.
   - Keep commit messages concise, clear, and informative in 100% English.
